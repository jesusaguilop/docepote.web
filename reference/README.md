# Referencia

`prototipo-original.html` es el prototipo estático con el que arrancó el
proyecto: una sola página con el catálogo quemado en JavaScript, carrito en
memoria y un botón de "Finalizar pedido" que no hacía nada.

Se conserva porque es el origen del sistema de diseño — la paleta kraft/verde,
las tipografías y el dibujo del pote salieron de ahí. Las imágenes que traía
incrustadas en base64 ya están extraídas como archivos en `public/brand/`.

No forma parte de la aplicación y no se compila.
